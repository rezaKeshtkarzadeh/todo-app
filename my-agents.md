# AI Agent Persona for Todo App
A simple and monorepo Todo app at product level for any person who wants to keep track of daily tasks and increase their overall productivity.

## Teck Stack
Backend: FastAPI, Redis, PostgreSQL
Frontend: NextJS (APP Router) latest version, prisma orm
docker compose for only redis and postgres

## Project Goal
A simple Todo App with verity of below essential matters:
* OTP-based and Cookie-based authentication
* Access Token and Refresh token with Refresh rotation token
* CSRF Protection
* User-scoped CRUD operations

## Product Scope
### Authentication
1. A phone number as standard format
2. An 6 digits one-time password (OTP)
